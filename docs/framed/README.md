## 메신저 사칭 (게임 시작 뒤 5·12·20분)

박 팀장 말투: 항상 "~습니다.", 이모티콘·ㅋㅋ 없음 (감사팀 단체방에서 확인할 수 있다).
1. Jenny Lee(본사): "첨부 파일이 몇 개?" → **"네. 첨부 3개입니다."**(예약 메일 첨부 3개)
2. 정 과장: "진술서 정말 괜찮은 거죠?" → **"괜찮습니다. 월요일까지는 아무 말 하지 마세요."** → 정 과장이 털어놓음(증거)
3. 최 상무: "아직 회사요?" → **"네. 보고서 발송 확인하고 바로 끄겠습니다."** ("집입니다"면 바로 순찰)

- 틀린 답은 의심 +1. 3분 안에 답이 없어도 +1이고, 상무 건은 바로 순찰이다.
- 의심 3이 되면 보안팀 순찰: 숨느라 **5분 손해**(한 번만).
