# 사내 점집 · 오늘의 업무 운세 (기획 완료, 개발 보류)

2026-11-10 기획 확정. 개발은 나중에 (사용자 결정). 로비 연결도 나중에.

## 파일
- `업무운세_DB_구성안.xlsx` — 문구 DB 전체 (964개). 시트: 개요 / 조합규칙 / 테마 / 한줄점괘 / 점괘_테마별 / 칼퇴팁 / 월루팁 / 조심할사람 / 한숨예보 / 상사기분 / 행운 / 부적 / 특별한날
  - 노란 칸(검토·메모)은 사용자 검토용. **사용자 검토는 아직 안 받음** → 개발 전에 검토 받기
- `data/` — 엑셀을 만드는 원본. `python3 data/build_db.py` 로 다시 생성 (그다음 수식 값 계산은 엑셀에서 열면 됨)
  - `build_db.py` 구조·샘플, `lines_batch1.py`·`lines_batch2.txt` 한 줄 점괘, `extra_data.py` 카드 문구·행운·부적·특별한 날
  - 개발할 때 이 파일들을 그대로 JSON으로 뽑아 쓰면 됨
- `mockups/` — 확정된 대시보드 시안 (`dash2_result.png` 결과 화면, `dash_empty.png` 첫 화면, `dash2.html` 원본)

## 확정된 내용
- 위치: 로비 새 섹션 **사내 점집** (파티 게임 / 방탈출 / 퍼즐 / 사내 점집). 메인 문구("회사에서 몰래 하는 딴짓" 등)는 아직 미정
- 입력: **이름 + 생일(월·일)**. 연도는 안 받음. 이 브라우저에만 기억, 서버 저장 없음. 생일로 별자리 표시
- 결과: 이름+생일+날짜로 정해짐(같은 입력이면 하루 동안 같은 결과). 공유 링크에 이름·생일을 담아 받은 사람도 같은 결과
- 화면(대시보드형): 조회 줄 → **한 줄 점괘 + 총운 결재 도장(승인/보류/반려)** → 카드 4개 **칼퇴 확률 / 월루 성공률 / 조심할 사람 / 한숨 예보** → **상사 기분 예보**(오전·오후 날씨, 기분지수) + **오늘의 행운**(메뉴·사무용품·방향·피할 시간) + **부적**(이미지 저장) → 동료에게 공유
  - 빠진 것(사용자가 별로라고 함): 회의 운, 메신저 운, 기운 흐름 차트, 7일 추이, 배지, 전일 대비
  - "팀장님 기준" 대신 "오늘의 결재 기상도"
- **테마 방식**: 날마다 테마 1개를 먼저 뽑고 숫자 범위·문구를 테마에 맞춤 (점괘와 카드가 이어지게). 테마 12개
  - 월요일 50% 월요병, 금요일 50% 금요일 테마. 나머지는 가중치, 어제와 같은 테마 안 나오게
  - **월급날 테마·월급날 D-n 칩은 삭제** (회사마다 달라서)
  - 점괘의 `{메뉴}` `{피할시간}` `{황금시간}`은 같은 날 다른 칸 값으로 채움
- 반복 방지: 이름+생일마다 1년치 순서를 섞어 두고 하루에 하나씩 → 1년 안에 같은 점괘 없음. 부적은 60종 다 본 뒤 반복
- 톤: 진지하게 시작해서 끝에서 비트는 위트 (사용자 OK)
- 특별한 날: 요일 보조 문구, 월초·월말·분기말, 새해, 명절 전날, 연휴 다음 날, 계절, 이브, 마지막 출근일, 13일의 금요일, **내 생일**(칼퇴 +15%p, 생일 문구)

## 개발할 때 할 일 (예상 4~6시간)
1. 사용자 검토 반영해서 문구 확정 → JSON
2. 결과 계산 로직(시드, 테마, 숫자 범위, 1년 순서 섞기, 특별한 날) + 1년치 자동 검사
3. 대시보드 화면(PC·모바일), 첫 화면, 이름·생일 기억, 공유 링크
4. 부적 이미지 저장, 보스키, GA(PAGE_TITLE·이벤트)
5. 테스트 서버에서만 먼저 공개(`preview`) → 확인 후 정식 오픈. 로비 섹션·메인 문구는 그때 같이
